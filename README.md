# 🎂 Interactive Birthday Card Animation 🐼💗

A lightweight, interactive 3D pull-to-reveal digital birthday card built using HTML5, CSS3, and vanilla JavaScript. Features smooth flip animations, pulsing glowing hearts, and floating particle effects — a fun, dependency-free demo that works on both mobile and desktop browsers.

---

## ✨ Features

- **3D Card Flip Animation:** Realistic card rotation effect on interaction.
- **Pull & Release Mechanism:** Interactive tab button that triggers the card opening.
- **Multi-Stage Scenes:** Smooth transition from the cover to a “Happy Birthday” banner, followed by floating blossom-heart particles.
- **Cute Panda & Hearts Theme:** Animated panda centerpiece with bouncing and pulsing effects.
- **Zero External Dependencies:** Built with pure HTML, CSS, and vanilla JavaScript — lightweight and fast.
- **Fully Responsive:** Adapts cleanly to mobile screens and desktop browsers.

## 🚀 Quick Start

### Option 1: Run Locally

1. Clone this repository:

```bash
git clone https://github.com/ROYALKINGKUNAL9090/Birthday.wishes-.git
```

2. Open the project folder and open `index.html` in your browser (double-click or serve with a static server):

```bash
# optional: serve using a simple HTTP server (Python 3)
cd Birthday.wishes-
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

### Option 2: GitHub Pages

- Enable GitHub Pages for this repository (Settings → Pages) and choose the default branch. The demo will be available at `https://<your-username>.github.io/Birthday.wishes-/` once published.
